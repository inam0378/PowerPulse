Milk shop app that runs on your phone, with no internet

Install once from this page. After that DoodhPulse works with WiFi and mobile data switched off: counter sale, morning and evening delivery, customer khata (udhaar), expenses, receipts and daily reports.

Your data, your responsibility

All data (customers, sales, khata, expenses and settings) is saved only inside this phone. It is never sent to Power Pulse or to any server, so Power Pulse has no copy and cannot recover it.

The shopkeeper alone is responsible for this data, including taking regular backups. If the app or Chrome's data is cleared, or the phone is reset, lost or damaged, the data is gone unless you have a backup file.

Install on Android

  1. Open this page in Google Chrome on the phone (internet needed only now).
  2. Tap Install on this device. If you do not see it: Chrome menu ⋮ → Install app (or Add to Home screen).
  3. Open DoodhPulse from the home screen once while online, so every file is saved.
  4. Switch the internet off. It keeps working.

First start

  • Enter the shop name, phone and language (English or Urdu).
  • Send the device code to Power Pulse to get your license key.

Backups

  • Home → Backup, or Settings → Download backup.
  • Keep it off the device: WhatsApp or Gmail it to yourself, or save it to Google Drive.
  • Do it at least once a week. A new or reset phone restores from this file (Settings → Restore backup). A new phone needs a new license key.

Printing

  • Uses Android's print system (58 mm receipts). Receipts can also go on WhatsApp.
  • For a thermal printer, install its print service app from the Play Store and switch it on in Settings → Connected devices → Printing.
